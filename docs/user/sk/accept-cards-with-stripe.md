# Prijímanie kariet cez Stripe

Popri Bitcoine a Lightningu môžete prijímať aj **platby kartou** cez **Stripe**. Je to Pro funkcia.

## Nastavenie

1. Otvorte obchod a prejdite na **Stripe**.
2. Pripojte svoj Stripe účet / zadajte Stripe údaje podľa pokynov.
3. Zapnite Stripe ako platobnú metódu.

Po pripojení si zákazníci môžu pri platbe okrem Bitcoin možností zvoliť platbu kartou.

## Poznámky

- Stripe vyžaduje plán **Pro** (viď [Plány a limity](/documentation/plans-and-limits)).
- Platby kartou sa vysporiadajú na váš Stripe účet, nie do Bitcoin peňaženky - je to samostatný platobný kanál, ktorú ovládate vy.
- Jednotlivé platobné metódy viete zapnúť alebo vypnúť v platobných nastaveniach obchodu.
