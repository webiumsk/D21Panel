# Kontakty

Kontakty sú zákazníci (a dodávatelia), ktorých dávate na doklady. Keď kontakt pridáte raz, môžete ho použiť na každej ďalšej faktúre.

## Pridanie kontaktu

Vo firme otvorte **Kontakty** a zvoľte **Nový kontakt**. Vyplňte potrebné údaje:

- Meno a adresa
- Daňové identifikátory (IČO, DIČ, IČ DPH)
- E-mail (použije sa pri odoslaní dokladu e-mailom)
- Predvolené platobné podmienky a bankové údaje, ak sú relevantné

## Import kontaktov

Máte existujúci zoznam? Použite **import** a načítajte kontakty z tabuľky (CSV/XLSX). Priraďte stĺpce raz a Satflux kontakty vytvorí alebo aktualizuje.

## Peppol / e-fakturačné ID

Ak posielate e-faktúry (napríklad slovenská e-fakturácia), vaši zákazníci môžu potrebovať Peppol participant ID. Satflux ho vie odvodiť z daňového ID, kde je to možné, a kontrolný zoznam pripravenosti na e-fakturáciu označí kontakty, ktorým ešte chýba.
