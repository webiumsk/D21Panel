# Connect a BTCPay store

A **store** is where your payments live. Satflux manages your BTCPay Server store for you and never exposes the underlying store ID.

## Create a store

New accounts start with a store. To add another, open **Stores** and choose **Create store**. Give it a name and default currency.

## Connect a wallet

A store needs a wallet before it can take payments - see [connect your first wallet](/documentation/connect-your-first-wallet). You can accept on-chain Bitcoin, Lightning, or both.

## What you can do in a store

- Create **invoices** (payment requests) and watch them get paid
- Add a **Point of Sale** for in-person payments
- Add **Pay Buttons** for your website
- Set up **Lightning addresses**
- Generate **API keys** and manage webhooks

## Access and security

Only you can see and manage your own stores. Satflux enforces this on every request, and sensitive actions are audit-logged.
